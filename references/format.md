# 笔画文件与运行

在含 SKILL.md 的目录运行。Python 3.9 或更高版本，无需安装额外依赖。

```sh
python scripts/write_letter.py assets/example.json assets/example.txt sample.svg
```

打开 sample.svg 即可看到「山外山。」。为另一位写信者建立私人的 JSON 副本，自选文字，新画代表字，把 UTF-8 正文存成独立文本，按相同顺序传入字帖、正文、SVG 输出路径。用换行安排停顿，空行保留。书写宽度超出一行时自动折行。

- 字形坐标默认 100 × 100，向右、向下为正。每一笔单独一个数组，整笔中的点按真实运笔顺序排列。`[x,y]` 可扩成 `[x,y,压力]`；默认压力为 1，0.2 可用来提锋，1.35 可用来顿笔。`[x,y,压力,true]` 保留折角。单点可作墨点。笔宽用坐标单位，倾斜用角度。
- `components` 保存可复用的笔画或部件。`parts` 每项为 `[部件键,[左,上,宽,高]]`，按当前字形的空间摆放。公开模板里的“山”示范了部件和变体。
- `glyphs` 的键可以是字、标点、字母、昵称或整个签名。匹配时取最长键，定义了整个词就可以一笔跨字，压力可在连接段下降。长词自行设置 `advance`（占宽，默认 100，至多 600），坐标可以超出单字的 100 宽度。要加大字写落款，可在单独的 SVG 分组中调整缩放和位置。
- 可选 `variants` 保存同一字的其他完整写法。渲染器按出现次序轮用；没有变体时用同一字形。要在特定昵称中用专属钩，直接定义整词。
- 可传 `--reference local-graphics.jsonl`。每行形如 `{"character":"某","medians":[[[x,y],[x,y]]]}`，使用 Make Me a Hanzi 的 1024 单位、向上为正坐标。自画字优先，本地参考补足其余。参考数据单独提供，保存其来源和许可说明。脚本会列出仍缺少的字符，补好后重新运行。
- 每个 SVG 内含原文，渲染前后都可核对。公开示例宜另用中性测试句，私人输出放在可控的私人目录，避免将私人字帖或带原文的图像上传公开项目。

## 简短例子

想让两个拉丁字母连写，可以添加一个整词键。下面只演示坐标和占宽；写信者可以自己决定笔形。正文遇到 `hi` 会优先走整词路径，最后一个单点是 i 的点。运行后在浏览器打开整封信，留意拱形和基线是否自然。

```json
{"hi":{"advance":96,"strokes":[[[8,76,0.4],[14,48,0.9],[29,14,0.7],[31,16,1],[23,35,0.9],[12,72,1],[28,52,0.6],[42,45,0.8],[38,62,1],[36,72,0.9],[45,72,0.5],[61,51,0.6],[65,47,0.8],[58,68,1],[62,74,0.7],[78,65,0.25]],[[71,30,1.1]]]}}
```
